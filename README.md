# Pinjaminstru - Peminjaman Instrumen Meteorologi

Website untuk melihat katalog dan meminjam instrumen dari Laboratorium Meteorologi.

🔗 **Demo:** https://yoruatia.github.io/Pinjaminstru/

## Fitur
- Katalog instrumen beserta status (tersedia, dipinjam, perawatan, terpasang di stasiun)
- Formulir peminjaman dan pengembalian
- Peta jaringan stasiun pengamatan

## Struktur Folder
| Folder | Isi |
|---|---|
| `frontend/` | Tampilan website (HTML, CSS, JS), di-deploy ke GitHub Pages |
| `backend/` | Server API (Node.js + Prisma) |
| `database/` | Skema, data awal, dan view database |
